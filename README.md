## Actividad Paquetes, Relaciones y Documentación

1. ¿Para que sirve package?

    - Un `package` (paquete) en Java es una forma de organizar y estructurar los archivos de código fuente. Sirve para agrupar clases relacionadas y evitar conflictos de nombres.

2. ¿Para que sirve import?

    - La palabra clave `import` en Java se utiliza para incluir clases o paquetes específicos en un archivo de código fuente, lo que permite acceder a sus funcionalidades sin tener que escribir el nombre completo de la clase.

3. ¿Qué relación existe entre package y directorio?

    - La relación entre `package` y directorio es que cada paquete en Java corresponde a un directorio en el sistema de archivos. Por ejemplo, un paquete llamado `com.example.prueba` se representaría como un directorio `com/example/prueba/` en el sistema de archivos.

4. ¿Qué es Javadoc?

    - Javadoc es una herramienta de documentación para el lenguaje Java. Permite generar documentación en formato HTML a partir de comentarios especiales en el código fuente, facilitando la comprensión y el uso de las clases y métodos.

5. ¿Qué diferencia hay entre // y /**...*/?

    - La diferencia entre `//` y `/** ... */` es que `//` se utiliza para comentarios de una sola línea, mientras que `/** ... */` se utiliza para comentarios de documentación (Javadoc) que pueden abarcar varias líneas y son procesados por la herramienta Javadoc para generar documentación.
